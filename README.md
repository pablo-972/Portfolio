# Portfolio
Personal portfolio built with the following technologies:

- React
- TypeScript
- Vite
- TailwindCSS


## Project Structure
The project is organized as follows:

```bash
src/
├── main.tsx        # application entry point
├── Router.tsx      # application routing
├── App.tsx         # main app structure
├── sections/       # portfolio sections
└── components/     # reusable UI components
```


## Run Locally
If you want to check the project locally, clone the repository and run:

```bash
npm install
npm run dev
````

The project will open on:

```bash
http://localhost:5173
```

Feel free to explore or modify the project files as needed.
